Static mockup · 1:1 with current app

Scope: typography + consistency only

This is the safe, conservative v1.1.0 — same exact layout, same colors, same buttons, same Apply-to-Clip placement as the current app. The only changes are typography and tiny consistency fixes. ~3 hours of work, low risk, ships independently.

Bolder hierarchy / structural changes (Apply to Clip promoted, Generate-vs-Generative rename, toolbar category labels, titlebar icons, multi-view scroll, keyboard shortcuts) are deferred to canvas-ui-v1-2-0-spec.html.

Hard rules preserved

  • · Sidebar never scrolls — top block sized to fit, no overflow.
  • · Multi-view canvas scrolls when params exceed visible rows (existing behavior).
  • · No new buttons, no removed buttons, no repositioned buttons.
  • · Color palette unchanged (10 accent colors stay — palette consolidation is v1.2 territory).
  • · Apply to Clip stays emerald in its current location (gradient promotion is v1.2).

What changed (typography pass only)

11 surgical fixes. No layout changes. No new features. No color changes.

1
Connection pill: text-[10px] → text-[9px]
Was 10px while every other titlebar button is 9px. One-pixel mismatch reads as "different element." Now matches.
2
Loop pill: bars-pill rebuild bug fixed
Static HTML used px-2 py-0.5; the JS rebuild after first click switched to px-3 py-1. Buttons grew on first interaction. Both sides now px-2 py-0.5. Same fix on Tool buttons. Numbers also dropped from text-[11px] → text-[9px] to match the rest of Row 0.
3
"Shapes:" label: text-[8px] → text-[9px]
Group label sat at 8px while the buttons it grouped were 9px. Label should never be smaller than the elements it labels.
4
"Saved:" label: text-[8px] → text-[9px]
Same fix as Shapes label. Both group labels in Row 1 now at 9px.
5
Tooltips added on every shape template + Clear Lane
Sine / Pump / Glitch / Groove / Chaos / Neuro had no tooltips. New users couldn't tell what they did. Each now gets a one-sentence "what it'll do" hint. Same fix on Clear Lane (also missing).
6
Stretch 2× / ½× buttons: text-[10px] → text-[9px]
These were the only buttons in Row 2 at 10px — leftover from when the group was meant to feel "louder." Now matches the rest of the row.
7
Param count: text-[8px] → text-[9px]
Param count read smaller than the section header. Now matches.
8
Track label: text-[8px] → text-[9px]
Same as #7. Sub-label was smaller than parent label by 1px — hierarchy was inverted.
9
Section headers (Edit, Generative): text-[8px] → text-[9px]
All sidebar section headers now at text-[9px] font-black tracking-[0.2em] text-zinc-500 — single token, applied everywhere. Was a mix of 8/9 with different tracking.
10
Dock Clear button: text-[8px] → text-[9px]
Companion action sat smaller than its own section label ("Recent Generations"). Now matches.
11
Keyboard hints: always visible (was hidden behind xl: breakpoint)
"Ctrl+Wheel · Space+Drag · Alt+Drag" was only shown above 1280px window width — invisible at most Stride window sizes. Now persistent so producers can discover the shortcuts that already exist.

Subtle global changes (no marker — applied throughout)

  • · font-weight: 300 dropped from Outfit URL (was loaded but never used — saves ~20kb per cold start)
  • · Letter-spacing scale collapsed: drop tracking-[0.3em] (5 uses, indistinguishable from tracking-widest at 9px) and tracking-tighter (1 use, replace with tracking-tight)
  • · Font weight rule applied: font-black only on caps section headers + primary CTAs; font-bold on everything else
  • · Lock-icon padding bumped p-1 → p-1.5 (24px touch target — barely visible visually, big difference for fat-finger producers)
  • · Empty-state copy fixed: "Connect M4L device and click Scan" → "Click Scan Mapped to load your rack" (button name has changed)
  • · Empty-canvas H2 text-lg → text-base (was the only text-lg in the canvas chrome)

What's NOT in v1.1.0 (deferred to v1.2.0)

Bigger changes saved for the next release — see canvas-ui-v1-2-0-spec.html:

  • · Apply to Clip promoted to brand-gradient hero — currently emerald; gradient promotion is a hierarchy decision worth landing carefully.
  • · "Generate" vs "Generative" naming conflict resolution — toolbar Generate (cloud) vs sidebar Generative (local). Rename one.
  • · Toolbar Row 2 category labels (Edit / Generate / Time / Select).
  • · Multi-view wheel-scroll handler + scroll indicator for racks > visible lanes.
  • · Keyboard shortcuts wired — Ctrl+Z / Ctrl+Shift+Z / Ctrl+S / Ctrl+A.
  • · Titlebar text buttons → icon-only (reclaims ~140px on Windows).
  • · Modal sweep — close-button standardization, header standardization, overlay backgrounds, z-index layers.
  • · Color palette consolidation — drop cyan + sky, retain 7 tokens max with semantic roles.
  • · Sidebar widening 224 → 256px (test against typical rack sizes first).

Effort + ship plan

~3 hours total. Single commit. Low risk. All changes are CSS class swaps + a few title attribute additions + a font URL trim. No JS logic touched.

Test plan: side-by-side the v1.0 build against v1.1.0 build at the same window size. Visually compare each row of the toolbar + each section of the sidebar. The redesign should look almost identical — that's the success criterion. If any element looks different, the consistency fix went too far.
