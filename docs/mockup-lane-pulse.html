Lane Pulse — 3 options

A glowing dot rides each lane's curve at playhead speed (x = track time, y = the curve's value there). All lanes stay in sync — like a playhead sweeping the loop.

Interpretation of "only when there's a raw lane": the pulse runs only on lanes that have a drawn curve. Empty lanes stay still (shown at the bottom of each option). Loop = 4s here. playing

Option AGlow Dot Clean white-hot dot with a soft purple halo. Minimal, never competes with the curve.
Subtlest. Reads as "this lane is live" without any extra geometry on the canvas.
Option BDot + Playhead Line The dot rides the curve while a faint vertical line marks the exact time position across all lanes.
Most "DAW-like" — the shared sweep line ties every lane to the same moment in the bar.
Option CComet Trail A short luminous tail trails the dot along the curve, lighting the path it just travelled.
Most energetic — the trail emphasises motion + direction. Best for the "alive / modulating" feel.
