Save is one click, on the lane. Hover any lane and a bookmark appears at the top right of the param box. Tap it: saved to Motions instantly, auto-named from the param and device. Rename lives in the toast, not in a modal. The toolbar Save ▾ does the same for the selection or all lanes. The old name-first dialog is gone.

One button, where Presets lives today. Motions opens as a drawer, not a modal, because the lanes are the target and they stay visible. Mine and Factory share one browser: search, favorites, bars filter, sparkline previews drawn from the real points. Hearted motions become the Pinned chips in the toolbar.

Browsing is auditioning. Hover the highlighted card: the curve ghosts onto the active lane, dashed. Click and it applies, undoable, and the drawer stays open so A/B between two candidates is two clicks. Drag a card onto any other lane to target it directly. Try it: hover, then click the Riser Sweep card.

Link: one curve, shown twice. Drag a cable from the port at the bottom left of a param box to another lane's port. The target adopts the source's curve, and from then on everything mirrors: drawing, tools, every roll. Each lane still scales through its own range, and an inverted member (±) receives the flipped move. Locked lanes sit out, as always.

Wrapper window shown without the left sidebar, for focus. Chrome, type and colors are the 1.3.4 copper skin. Keys 1 to 4 switch scenes.

The spec, condensed

Part 1 · MotionsThree ways to save, zero modals

  • On the lane: hover reveals the bookmark, click saves. Auto-name Param · Device, toast offers Rename and Undo.
  • Toolbar Save ▾: selected lanes if a selection exists, else the active lane. Menu: Active / Selected / All lanes.
  • In the browser: first cell of Mine is + Save current motion.
  • Multi-lane saves remember each lane's param + device, so re-apply matches by name first, order second.

Part 1 · MotionsThe drawer, not a modal

  • Slides from the right over the inject rail; every lane stays visible, which is what makes ghost preview possible.
  • Tabs Mine / Factory / All: the factory Preset Bank folds in as Factory, ending the four-surface fragmentation (Shapes strip, Preset Bank, Saved chips, All Presets).
  • Cards render sparklines from the stored points, no image files.
  • Heart a motion and it becomes a Pinned chip in the toolbar: your go-to moves, one click.

Part 1 · MotionsApply rules + storage

  • Points stored normalized (t, v, curve), so any motion fits any param; the lane's own range does the scaling.
  • Default apply fits the current loop; the card menu offers Apply at native length (sets the lane loop boundary).
  • Locked lanes are never written.
  • Store: stride-data/motions.json via the prefs channel (favorites pattern), never localStorage-only. Existing presets migrate on first boot: nobody loses a save.
  • Export / import one motion as a .stridemotion file. Packs later.

Part 2 · LinkWhy it's right for Stride

Paste To is the static version of this feature; Link makes it live. The cable and jack language already exists in the inject rail, lanes are already normalized with engine-owned ranges, so "same pattern, different ranges" is how the engine thinks today. And it unlocks the classic move: cutoff up while reverb ducks, one drawn curve, one member inverted.

Honest costs: the 148px param box is dense (placement below is the answer), link groups must be engine-owned state v7 like locks and speed, and the group rules table needs to exist before code. It does now.

Part 2 · LinkGroup rules

Link A → BGroup forms, B adopts A's curve (source wins), one undo step
Any edit / toolMirrors to every member; inverted members receive 1 − v
Motion toolsOne roll per group, not per lane (S&H reroll included)
Locked memberFrozen, receives nothing; re-syncs on unlock (undoable)
ShuffleA group occupies one slot; membership never changes
Lane speed / loopStay lane-local: both at 1x = identical motion, different = phased echoes of the same move
CablesOn demand only: while dragging, on chip hover, hold L, and ~1.2s after a link lands. Never parked over the curves.
