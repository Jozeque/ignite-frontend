StrideQuick · Device Build Guide

Build the Quick panel inside StrideLink

A folding panel of one-click shortcuts that drive the Stride canvas without leaving Ableton. The whole brain is already built. You are wiring buttons to one object you already have: node.script.

The idea

Two wires, one object

Your StrideLink device already contains a node.script server.js object. It runs the connection to the Stride app. You do not touch any code. You only add Max objects around it:

  • Buttons out: each button sends a tiny text message like quick chaos into node.script. node.script forwards it to the app, which runs the matching canvas action instantly.
  • Numbers in: node.script sends back quick_state 12 12 8 1 for your counter and connection light.
You never edit code. server.js already understands every quick … message and already sends quick_state back. This guide is 100% Max patching.

1Prove it with one button

A single message into node.script

Before building the whole panel, prove the pipe works. In your StrideLink patch (Edit mode), make one message box and connect it to node.script's left inlet.

  • Double-click empty patch space, type m, press enter → a message box appears.
  • Type inside it: quick chaos
  • Drag a cord from the message box's bottom-left outlet to node.script's top-left inlet.

Test now: open the Stride canvas (the existing Open Canvas button), draw a curve on a couple of lanes, then click your quick chaos message box. Every lane should fill with Chaos instantly.

If that worked, you are done with the hard part. Every other button is the exact same move with different text.

3Wire the readout

Counter and connection light

node.script sends back one message: quick_state <on_chain> <on_canvas> <bars> <connected>. Catch it and split it into four numbers.

  • From node.script's left outlet (the same one feeding your existing objects), branch a new route quick_state.
  • Connect route quick_state → unpack 0 0 0 0.
  • unpack has 4 outlets, left to right: on chain, on canvas, bars, connected.
  • on chain / on canvas → two number boxes (or live.numbox). Shows “params the device sees / lanes loaded on canvas”.
  • bars → use it later to light the active loop button (optional polish).
  • connected → a live.toggle or a colored panel as a connection LED (1 = app open, 0 = grayed out).
Can't find the right node.script outlet? Any of your existing objects (like the route that already handles status / command) hangs off it. Branch your new route quick_state from that same outlet. Adding a second route in parallel changes nothing about the existing routing.

4Make it look native

Lay it out in Presentation

Select your buttons and readout, right-click → Add to Presentation. Switch to Presentation mode (the icon at the bottom of the patcher) and arrange them. Match Stride's look: dark charcoal background, copper/amber buttons, grouped rows.

Colors: Stride's device palette is charcoal #161616 with copper/amber buttons #f5a524, green for the connection LED, and the orange→fuchsia gradient reserved for Inject. live.text colors are set per object in the Inspector.

5Make it fold

One toggle hides the whole cluster

Build everything always-visible first and get it working. Then add folding last. The clean way: put all the Quick buttons inside one bpatcher (a sub-patch that displays inside the device), give that bpatcher a Scripting Name like quickPanel, and show/hide just that one object.

  • Add a live.text in Toggle mode, label “Quick ⌄”. It outputs 1 (open) or 0 (folded).
  • Wire it to sel 1 0. The left outlet bangs on 1, the next on 0.
  • 1 → message script show quickPanel → thispatcher
  • 0 → message script hide quickPanel → thispatcher
Don't want a bpatcher? You can hide objects individually by giving each a Scripting Name and sending script hide name1, script hide name2 … to thispatcher. The bpatcher is cleaner because it's a single name to toggle. Either way, the device window stays one size; folding just clears the button area.

Test checklist

Five checks before you call it done
  • Connection: open the canvas. The connection LED should go green (connected = 1).
  • Counter: scan a rack. Both numbers should fill in (chain / canvas).
  • A generator: click quick chaos. Every lane fills with Chaos on the canvas, even if its window is behind Ableton.
  • Loop: click the 16 button. The canvas loop length jumps to 16 bars.
  • Inject: click Inject to Clip. The curves write into the selected Session clip.
If a button does nothing: check the Max window (right-click the device → Max Window). server.js prints Stride quick: chaos when it receives a press. No line = your message box isn't reaching node.script's inlet. A line but no canvas change = the canvas app isn't open.
