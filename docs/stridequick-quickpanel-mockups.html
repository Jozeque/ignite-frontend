A · Lane Stack

Every param is a full-width strip you draw on directly, stacked like a mixer, each ending in its own patch jack + cable-colored curve. Label column carries the select checkbox + name + lock; live value on the right. The slider tray applies to whatever's checked. Best for: seeing and editing all lanes at once, closest to today's multi-lane canvas. Trade-off: each lane is short, so very fine point work is tighter.

C · Overlay Patchbay

The most on-brand for this skin: every lane is a colored patch cable leaving a jack in the left bay and routing across one shared scope, so you see how params relate. The chip rail is the param list: click to arm a cable for drawing (multi-arm to paint several), lock to freeze. Armed cables draw bold with handles; the rest stay dim. Best for: shaping curves in relation to each other. Trade-off: busy with many lanes (mitigated by dimming + arm).
