HOW TO LOAD INTO MAX
  Max's Inspector has no "import palette file" button — the reusable palette is
  the Swatches strip inside the color picker. You fill it once and it is then
  available on every object, in every device:

    1. Select an object, click a color attribute in the Inspector → the color
       picker opens.
    2. Paste a HEX from below into the picker's hex (HTML) field, press Enter.
    3. Click the "+" on the Swatches row to pin it.
    4. Repeat for all 10. Done — they now show up for every object you color.

  If you set colors in patch text / JSON instead, use the RGBA floats (0–1).

      Mutate   Text/Border = sage   #86a87f

      2x / ½x  Text/Border = teal   #5e9aad

  Open Canvas     same copper fill as Inject (the two warm CTAs)
