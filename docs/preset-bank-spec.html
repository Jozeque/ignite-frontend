Overlap Analysis

Bloom vs Weave Chase

Both copy the source curve to all lanes with phase shifts. Bloom also applies inversion + mirror + amplitude changes (10 fixed recipes). Weave Chase is pure even-phase distribution, cleaner and more predictable.

Overlap: ~60%. Bloom is "artistic variation", Weave Chase is "mathematical distribution". Both useful but the phase-shift part overlaps.

Weave Fill vs Paste Inv + Paste To

Both can create "opposite" curves on other lanes. But Paste Inv is a simple 1-value flip. Weave Fill is activity-aware — it generates movement specifically where the source is still.

Overlap: ~20%. Fill is fundamentally different (gap analysis), just solves a similar high-level goal.

Chaos vs Glitch Template

Both generate random shapes. Chaos uses 8 algorithmic shape types across all lanes. Glitch template generates binary spikes on the active lane.

Overlap: ~40%. Chaos is multi-lane random fill. Glitch is single-lane random spikes. Different scope but similar energy. Could Glitch just be part of Chaos?

Mutate vs Chaos

Mutate takes an existing curve and scrambles it (shuffle segments, flip chunks, add/delete points). Chaos generates from scratch. Mutate needs input; Chaos doesn't.

Overlap: ~15%. Different intent — Mutate = "variation of what I have", Chaos = "give me something new".

Potential consolidation: Bloom and Weave Chase both do phase-shifted copies. Consider: rename Bloom to something else, or merge its inversion/mirror transforms INTO Weave as additional options (a "Variation" slider alongside the Spread slider). This would give one tool — Weave — with modes: Chase (pure phase), Fill (counterpoint), and Bloom (variation recipes). Fewer buttons, more power per button.

The Problem

100 parameters with random automation = noise. 100 parameters with intentional relationships = sound design that breathes, grooves, and evolves. The preset bank needs a system — not hand-drawing, not randomness.

Core principle: A few root curves define the macro story. Everything else is derived. The listener hears one cohesive movement, not 100 independent wiggles.

Lane Hierarchy

Every preset is built from 3-5 root curves. The other 95+ lanes are mathematically derived from these roots.

Root Lanes

3–5

Hand-crafted curves on highest-impact params. Filter cutoff, wavetable position, main FX wet/dry. These ARE the sound.

Secondary Lanes

10–15

Derived with clear relationships: inverse, phase-shifted, scaled. Resonance countering cutoff. Delay echoing the filter sweep.

Tertiary Lanes

80+

Micro-variations and fills. Subtle movement at 5-15% intensity. Textural shimmer. Phase-cascaded across chain params.

Root Curve Archetypes

The 5 building blocks. Every root lane is one of these shapes (or a combination).

Sweep

Slow directional movement

Ramp up, ramp down, S-curve, or arc. 4-16 bar movement. The "journey" of the sound — filter opens, wavetable morphs, reverb grows.

Pulse

Rhythmic repeating pattern

Sidechain pump, gate, sawtooth LFO. Tempo-synced. Creates rhythm from static sounds. The heartbeat of the preset.

Accent

Sparse impactful moments

Stabs, drops, peaks. Mostly silent, then hits hard. Creates punctuation — the moments that make you rewind. Best on FX sends, drive, pitch.

Drift

Organic micro-movement

Slow random walk, gentle wobble. Never repeats exactly. The "alive" quality — subtle detuning shifts, chorus depth wandering. Barely audible, deeply felt.

Build

Escalating intensity

Linear ramp, exponential curve, or staircase. Creates tension — the thing that makes a drop hit. Filter opening, drive increasing, reverb swelling. Solid line = exponential, dashed = staircase variant.

Derivation Methods

How root curves become 100 lanes. Each method creates a specific musical relationship.

Phase Cascade
Same shape, each lane offset by 1/N of a cycle. 10 filters = peaks at 10 different moments. Traveling wave. Uses Weave Chase.
Counter
Inverse relationship. When root goes up, derived goes down. Cutoff rises → resonance dips. Scaled by importance — secondary at 80%, tertiary at 30%.
Echo
Same shape, delayed 1-2 beats, reduced amplitude. Creates depth — like reverb for automation. Drive echoes filter sweep. Delay feedback echoes cutoff.
Fill
Active where root is still, holds where root moves. True counterpoint. Root sweeps filter → fill lane holds. Root holds → fill lane moves. Uses Weave Fill.
Micro
Root shape at 5-15% amplitude. Almost invisible, deeply felt. Textural shimmer — subtle detuning, chorus depth, stereo width. Applied to 80+ tertiary lanes.
Harmonic
Root shape at 2x or 3x speed. Adds rhythmic interest on top of the macro movement. A filter sweep with double-time resonance flutter on top. Dashed = root, solid = 2x.

Counter-Motion Rules

What should complement what. These aren't arbitrary — they're how synthesis actually works.

Filter cutoff rises → Resonance dips

Prevents ear-piercing resonance at high cutoff. The classic subtractive synth move.

Drive increases → Wet/dry decreases

Prevents mud. More saturation = less effect processing needed. Keeps the mix clean.

Delay feedback rises → Delay time holds steady

Prevents runaway feedback. If both move simultaneously, you get chaos (sometimes desired — see Glitch category).

Reverb size grows → Dry signal compresses

Creates depth without wash. The space opens up while the source gets tighter. Cinematic technique.

Multiple filters → Staggered phases

Traveling wave, not a wall. 10 bandpass filters all peaking at different times = evolving movement. All peaking together = one big filter.

Oscillator detune rises → Filter cutoff drops slightly

Wider detuning = brighter harmonics. Compensate with a darker filter to keep the tone balanced.

LFO rate increases → LFO depth decreases

Fast + deep = gargle. Fast + subtle = shimmer. Slow + deep = sweep. Scale inversely for musicality.

Wavetable position sweeps → Volume micro-compensates

Different wavetable positions have different perceived loudness. Subtle volume counter keeps energy consistent while timbre changes.

Preset Categories

100 presets across 8 categories. Each category has a specific root pattern and character.

The Pumper

12 presets
Evolving Pulse + Counter-reactive lanes

Not a boring loop. The pump shape changes every bar — deeper, shorter, syncopated. Derived lanes REACT to the pump's intensity: when the pump hits hard, resonance ducks. When it softens, effects bloom. Constantly evolving rhythmic engine.

Slow Burn

12 presets
Sweep + Drift + Reactive secondaries

Glacial movement. 4-16 bar arcs where the sound morphs so slowly you don't notice until it's somewhere completely different. Derived lanes wake up and contribute during the sweep's flat zones. Cinematic. Hypnotic.

Surge

12 presets
Build + Accent + Reactive release

Rising tension → impact → aftermath. The build isn't linear — it stutters, pauses, fakes out. Derived lanes pile on as intensity increases. At the peak, half the lanes snap back while others ring out. The drop isn't one moment — it's a cascade.

Ghost Machine

12 presets
Drift + Micro-sweep + Fill-reactive

You can't hear it working, but you feel it. Micro-movements at 5-15% intensity across 80+ lanes. Nothing repeats. Nothing is on the grid. The sound is alive without any obvious modulation. Strip it away and the sound dies. Add it back — magic.

Nerve

12 presets
Fast Pulse + Sweep underlayer + Reactive intensity

Aggressive, complex, twitchy. Fast rhythmic movement (16th/32nd) with a slow sweep underneath that changes the character. When the sweep reaches certain zones, the pulse behavior shifts — doubles speed, adds accents, opens up. The lanes track the tension.

Deep Breath

10 presets
Sweep arc (inhale/exhale) + Reactive fill

Inhale: everything opens — filters, space, width. Exhale: everything closes, tightens, compresses. Not just a ramp — the derived lanes participate differently on the inhale vs exhale. Some wake up on the exhale. Some only exist at peak. Organic respiratory motion.

Chaotic Engine

10 presets
Accent (random) + Fast Pulse + Broken rules

Deliberate disorder. Counter-motion rules are BROKEN — delay time AND feedback move together. Resonance peaks WITH cutoff. The chaos has structure though — energy flows in waves, not constant noise. Moments of clarity between the madness.

Cascade

10 presets
Phase cascade from single root + Reactive intensity scaling

One curve ripples across 100 lanes like a wave through water. But each lane doesn't just phase-shift — it ADAPTS. The first lanes hit hardest, the last lanes are whispers. The wave shape itself mutates as it travels. Stunning with 30+ filters.

Sculpted

10 presets
Accent + Counter + Hand-crafted moments

Precision. Sparse, deliberate movements — a filter opens on beat 3 of bar 2, reverb blooms on bar 4, drive kicks on the and-of-1. Every move is placed, not generated. Derived lanes support each moment with reactive counter-motion. For producers who want control.

Reactive Derivation — The Key Concept

Static derivation: "resonance is always the inverse of cutoff." Reactive derivation: "resonance BEHAVES DIFFERENTLY depending on what cutoff is doing right now."

The root curve is divided into zones based on its behavior: high-energy zones (peaks, fast movement), low-energy zones (holds, valleys), transition zones (ramps). Each derived lane gets a different recipe per zone:

Root zoneExample: Resonance (secondary)Example: Delay send (secondary)Example: Chain volume (tertiary)
Peak (root is high)Ducks to 20% — safetyHolds at 0% — no smearMicro-wobble at 5% — shimmer
Ramp (root is moving)Counter-sweeps at 50%Rising slowly — builds spacePhase-cascaded pulse — traveling wave
Valley (root is low/still)Rises to 70% + adds LFO wobblePeaks — fills the quiet with spaceActive fills — movement in the gaps
Accent (root spikes)Snaps to 0 — hard contrastSpike echo — delayed reflectionAll lanes pulse together — impact

This means the same derived lane sounds different in bar 1 (tight pump) vs bar 3 (open, softer). The preset evolves because the relationships evolve.

Generation Pipeline

How we actually build 100 presets programmatically.

StepWhatHow
1Define root archetype library5 archetypes x 4-6 variants each = 25-30 root shapes as point arrays
2Create category configsEach of 100 presets gets: category, root selections (3-5), bars, genre timing
3Generate root lanesPick root shapes, apply timing rules, assign to impact params
4Derive secondary lanesApply derivation methods (counter, echo, fill, phase) based on counter-motion rules
5Generate tertiary lanesPhase cascade + micro for remaining 80+ params
6Export as sessionsJSON files matching Stride's session format, loadable from canvas UI
7Bundle with appShip in stride-vst/app/presets/, add Preset Browser to canvas

Key insight: The presets are rack-agnostic. They define automation shapes for N lanes — when loaded, they map to whatever rack is currently scanned. A "Techno Pump Engine" preset works on Serum, Wavetable, Operator, or any rack. The shapes adapt to the param count.
