Stride, interface study

Buttons that behave like hardware.

Three directions, each shown sitting in the real toolbar so you can judge them in context rather than on a swatch board. Every colour is lifted from the landing page tokens, which the app's own copper skin already matches. Click any button below to toggle it and feel the on and off states.

What is actually wrong today. Every button in renderer/index.html is the same shape: a bg-hue-500/5 translucent fill, a border-hue-500/20, and text-hue-400. That tinted ghost rectangle is the default any code generator reaches for, which is exactly why it reads as a mockup. Three things follow from it: no material, since there is not a single box-shadow in the toolbar, so nothing can look pressed. No body, since py-0.5 is two pixels of vertical padding. And no hierarchy, since seven hues compete at equal brightness, so colour ends up sorting tools into families instead of telling you what is switched on.
What the wordmark tells us. The logo is black weight, tight, squared, letters nearly touching, on a copper gradient. The toolbar is font-bold nine pixels with tracking-wider. It is loose and thin where the mark is heavy and tight. All three options below move to weight 800 or 900, drop tracking from .1em to .045em, and go up to 10px with a 22px minimum height. I stopped at .045em rather than the wordmark's near-zero: small uppercase type needs a little air or it turns to mush at 10px. That is the one place I did not follow the logo literally.
TodayWhat ships now

The baseline, rebuilt faithfully from the live Tailwind classes so the comparison is honest.

Option AMachined Cap

A milled keycap. At rest every button is the same neutral metal, raised, with a lit top edge and a shadow under it. Press it and it physically sinks: the gradient inverts, an inner shadow appears, and only then does the family colour arrive, glowing from inside with a filament along the floor of the cap. Hue stops being decoration and becomes the signal for on. This is the closest to Minimal Audio, and the safest.

Strength
Reads instantly. A dark toolbar with three lit caps tells you the whole state of the instrument at a glance.
Cost
Loses the at-rest colour coding, so you can no longer tell Copy from Swing by hue alone. Grouping and dividers carry that job instead, which they already do.
Risk
Low. Nothing else in the layout moves.
CSS
/* off, raised metal, no hue */
background: linear-gradient(180deg,#2e2a23 0%,#211d18 55%,#1b1813 100%);
border: 1px solid #100e0b; border-top-color: #3b352c;
box-shadow: inset 0 1px 0 rgba(255,255,255,.085), 0 1px 2px rgba(0,0,0,.65);
color: #968d81;

/* on, sunken and lit from within */
background: linear-gradient(180deg,#171410,#1e1a14);
box-shadow: inset 0 2px 5px rgba(0,0,0,.75),
            inset 0 -1px 0 rgba(255,255,255,.05),
            0 0 0 1px rgba(var(--acc-rgb),.22);
color: var(--acc-lt);
text-shadow: 0 0 9px rgba(var(--acc-rgb),.55);
Option BSignal Lamp

The cap never changes material at all. A lamp under the label does. Off, it is a dead grey bar; on, it lights in the family colour and bleeds a little of that light up onto the face. This is how a real unit reads across a dark room: black plastic everywhere, and your eye goes straight to the LEDs. The densest of the three, and the quietest.

Strength
Keeps every family colour readable while off, so Copy still reads teal and Clear still reads rose. Scales best as the toolbar grows.
Cost
Needs 3px more height per row for the lamp. Across three rows that is 9px off the canvas.
Risk
Low to medium. The lamp is small; on a dim laptop panel it carries less far than A's whole-cap shift.
CSS
/* the cap is inert, the lamp is the whole story */
background: #1c1915; border: 1px solid rgba(216,201,176,.09);
padding: 4px 10px 7px;  /* the extra 3px is the lamp's room */

.b::after {                     /* the lamp itself */
  position: absolute; left: 7px; right: 7px; bottom: 3px; height: 2px;
  background: #2c2620;        /* dead */
}
.b.on::after {
  background: var(--acc-lt);
  box-shadow: 0 0 5px rgba(var(--acc-rgb),1), 0 0 11px rgba(var(--acc-rgb),.62);
}
.b.on { background-image: linear-gradient(0deg,rgba(var(--acc-rgb),.16),transparent 62%); }
Option CEngraved Plate

Off, the label is cut into dark metal: dark type with a one pixel light edge under it, the way engraving catches light. On, the plate fills with the wordmark's own copper gradient and the type flips to near black. It is the landing page's .btn-copper and the logo, quoted exactly, sitting in the toolbar. At rest the whole bar is quiet engraved brass; the active tool is the only lit thing on screen.

Strength
The only one of the three that could not belong to another product. Ties plugin, site and wordmark into one language.
Cost
Loudest by far when several tools are on at once. Wants a discipline where few things are active together, which suits Point or Free and the generator row but fights the Stretch cluster.
Risk
Medium. Worth trying restricted to primary actions, with A used for the secondary rows.
CSS
/* off, engraved: dark type + a light edge BELOW it */
background: linear-gradient(180deg,#232019,#1a1712);
border: 1px solid rgba(0,0,0,.55);
box-shadow: inset 0 1px 0 rgba(255,255,255,.055), 0 1px 1px rgba(0,0,0,.45);
text-shadow: 0 1px 0 rgba(255,255,255,.055);
color: #7d7468;

/* on, the wordmark gradient, verbatim from the landing .btn-copper */
background: linear-gradient(180deg,#e58a2e,#c6712b);
color: #180f04;
text-shadow: 0 1px 0 rgba(255,231,197,.42);
box-shadow: inset 0 1px 0 rgba(255,255,255,.34), 0 2px 9px -3px rgba(198,113,43,.85);
One change that applies whichever you pick. Today hue sorts tools into seven families of equal brightness. I would cut it to five and make each one mean something: copper for anything that generates motion, teal for transforms that move a curve you already have, gold for time, sage for a persistent on state such as Rescan, and rose for the two destructive actions. Everything else stays neutral metal. That is what the mockups above use, and it is why they look calmer than the current bar even before the material lands.
