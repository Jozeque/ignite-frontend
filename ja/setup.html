セットアップ

Stride は、あなたの音源とエフェクトをホストし、演奏中にそのノブを動かす VST3 プラグインです。Ableton Live では StrideBridge がセット自身のデバイスも同じキャンバスに加えます。

最初に一度だけインストール

01

プラグインをインストールする

まず Stride.vst3 を VST3 フォルダーに入れて、DAW で再スキャンしてください。macOS ではインストーラーが Audio Unit も配置するので、Logic の Instrument スロットに表示されます。

WinC:\Program Files\Common Files\VST3
Mac/Library/Audio/Plug-Ins/VST3
02

StrideBridge を User Library に追加するAbleton のみ

StrideBridge のフォルダーごと、ファイルをまとめたままコピーしてください。デバイスは隣にあるファイルを必要とします。

WinDocuments\Ableton\User Library\StrideBridge
Mac~/Music/Ableton/User Library/StrideBridge

手順

01

トラックに Stride を置く

動かしたい音源とエフェクトを、その中に読み込みます。

02

StrideBridge を好きなトラックにドラッグするAbleton のみ

1セットに1つです。オーディオをそのまま通すので、どこに置いても構いません。bridge を認識すると Stride に MAP LIVE ボタンが表示されます。

03

動かしたいノブをマッピングする

Stride の中のノブに触れるか、MAP LIVE を押して Live セット内のどこかのノブをクリックします。ひとつずつレーンになります。もう一度ボタンを押すとマッピングが終わります。

04

動きを描くか、回して出す

カーブを手で描くか、ジェネレーターを押して各レーンに一度に違うカーブを出します。決まったものは固定して、残りはもう一度回してください。

05

Play を押す

ノブはトランスポートに乗って動きます。作業中にクリップへ書き込まれるものはありません。Live の Export、Freeze、Bounce はオフラインでレンダリングされるので、その動きをファイルに残すには、INJECT を押して本物のオートメーションとして書き込むか、トラックをリアルタイムでリサンプリングしてください。Stride の中で動いているものは通常どおりレンダリングされます。

任意 · カーブをクリップに書き込む

Live で手で編集できる本物のオートメーションとして動きが欲しい場合、または Stride を外したあともセットに残したい場合だけです。ほとんどのセッションでは必要ありません。

01

StrideInject を有効にして、Live を再起動するAbleton のみ

有効になっていないと、デバイスのボタンは STRIDEINJECT?

Preferences › Link, Tempo & MIDI › Control Surface › StrideInject
02

クリップを選んで INJECT を押すAbleton のみ

まず MIDI クリップを選んで Live のディテールビューに表示させ、それからデバイスの INJECT を押します。レーンがそのクリップの本物のオートメーションになります。Ctrl または Cmd Z で元に戻せます。

03

ボタンの下の数字を見てください

書き込めるのは、ノブがそのクリップ自身のトラックにあるレーンだけです。これは Live の仕様で、こちらの制限ではありません。 4 OF 6 は、4つが書き込まれ、2つが別のトラックを指しているという意味です。その2つは、それぞれのトラックのクリップで書き込んでください。

必要な環境

 

Stride は Windows 10/11 と macOS 11 以降のあらゆる VST3 ホストで動き、Logic と GarageBand では Audio Unit として動きます。StrideBridge には Max for Live 入りの Ableton Live 11 以降が必要で、Live Suite には最初から含まれています。Pro Tools (AAX のみ) には対応しません。
