FAQ

The questions everyone asks

Does Stride work on audio tracks? ▾
Not directly. Stride writes automation into MIDI clips, which only exist on MIDI tracks with instrument racks. Workaround: load your audio into a Sampler instrument, draw a held C3 note in a MIDI clip, then treat that Sampler track like any other instrument rack. Stride can automate every Sampler parameter (filter, envelope, FX) the same way it would automate a synth.
Can I use Stride for mixing? ▾
Probably not. Stride uses a draw-first / hear-after workflow — you design curves visually, then drag the .alc into Ableton to hear them. Great for creative exploration, slow for the tight feedback loop a mix needs. Use Stride for sound design and creative variation; use Ableton's native automation lanes for surgical mix work.
Which Ableton edition do I need? ▾
Live 11 or 12, Suite edition (includes Max for Live). If you have Standard, Stride works with the Max for Live add-on. Lite and Intro are not supported — they don't include M4L.
Does it work on Mac and Windows? ▾
Both. Mac on macOS 11+ (Intel and Apple Silicon native), Windows on Windows 10/11.
Can I get a refund? ▾
Yes — if Stride doesn't fit your setup, email us within 14 days for a full refund. No interrogation, no hoops.
How many machines can I install on? ▾
Two — your studio + laptop, or main + backup. One license, two activations.
Will it work with FL Studio / Logic / Bitwig? ▾
No. Stride uses Max for Live to talk directly to Ableton's rack parameters. It can't run anywhere else. If you don't use Ableton, Stride isn't for you.
Is it AI? ▾
No. Stride generates curves with deterministic math (bezier, randomized within musical constraints). What it makes is yours — no cloud, no model, no learning from your data. Just patterns running through math you control.
